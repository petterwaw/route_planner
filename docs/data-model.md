# Model danych

Tabele bazy i zasady migracji. Czytaj przy pracy nad encjami i migracjami.

## Zasady

- Baza: H2 w pliku `backend/data/zdaze`. SQL ma być przenośny (Postgres), bez składni specyficznej dla H2.
- Schemat zmienia tylko Flyway. Hibernate działa w trybie `validate`.
- Klucze: `BIGINT GENERATED BY DEFAULT AS IDENTITY`.
- Chwile w czasie (`created_at`, `computed_at`, `logged_at`): `TIMESTAMP WITH TIME ZONE`, w Javie `Instant`.
- Wartości planu: `DATE` i `TIME` (lokalne dla `Europe/Warsaw`), w Javie `LocalDate` i `LocalTime`.
- Typy wyliczeniowe jako `VARCHAR` z nazwą wartości.

## Migracje

| Wersja | Zawartość | Etap |
|---|---|---|
| V1 | `settings` z jednym wierszem | 1 |
| V2 | `place`, `event` | 2 |
| kolejna wolna | `leg_snapshot` | 3 |
| kolejna wolna | `api_usage` | 5 |
| kolejna wolna | `trip_log` | 7 |

Numer nadajesz w chwili tworzenia migracji. Istniejących migracji nie edytujesz.

## settings

Zawsze dokładnie jeden wiersz, `id = 1`.

| Kolumna | Typ | Uwagi |
|---|---|---|
| `id` | SMALLINT | PK, CHECK `id = 1` |
| `home_label` | VARCHAR(60) | NOT NULL, domyślnie `Home` |
| `home_address` | VARCHAR(255) | NULL, dopóki użytkownik go nie poda |
| `arrival_buffer_min` | INT | NOT NULL, domyślnie 5, zakres 0–60 |
| `updated_at` | TIMESTAMP WITH TIME ZONE | NOT NULL |

## place

| Kolumna | Typ | Uwagi |
|---|---|---|
| `id` | BIGINT | PK |
| `name` | VARCHAR(80) | NOT NULL, UNIQUE |
| `address` | VARCHAR(255) | NOT NULL, tekst zrozumiały dla wyszukiwarki tras |
| `created_at` | TIMESTAMP WITH TIME ZONE | NOT NULL |

Miejsca używanego przez punkt planu nie można usunąć.

## event

| Kolumna | Typ | Uwagi |
|---|---|---|
| `id` | BIGINT | PK |
| `title` | VARCHAR(120) | NOT NULL |
| `place_id` | BIGINT | NOT NULL, FK do `place(id)` |
| `recurrence` | VARCHAR(10) | `WEEKLY` albo `ONCE` |
| `day_of_week` | VARCHAR(9) | `MONDAY`…`SUNDAY`; wymagane dla `WEEKLY`, puste dla `ONCE` |
| `event_date` | DATE | wymagane dla `ONCE`, puste dla `WEEKLY` |
| `start_time` | TIME | NOT NULL |
| `end_time` | TIME | NOT NULL, CHECK `end_time > start_time` |
| `valid_from` | DATE | NULL; tylko `WEEKLY` |
| `valid_until` | DATE | NULL; tylko `WEEKLY` |
| `source` | VARCHAR(10) | `MANUAL` albo `IMPORT` |
| `created_at` | TIMESTAMP WITH TIME ZONE | NOT NULL |

Indeksy: (`recurrence`, `day_of_week`) oraz (`event_date`).

Ograniczenie MVP: punkt planu nie przechodzi przez północ.

## leg_snapshot

Pamięć podręczna wyników dostawcy tras dla odcinka. Opis działania: `docs/architecture.md`, sekcja „Pamięć podręczna i limity".

| Kolumna | Typ | Uwagi |
|---|---|---|
| `trip_date` | DATE | część PK |
| `leg_key` | VARCHAR(40) | część PK; `to-event-{id}` albo `home` |
| `kind` | VARCHAR(10) | część PK; `PLANNED` albo `LIVE` |
| `input_hash` | VARCHAR(64) | skrót danych wejściowych zapytania |
| `payload` | CLOB | JSON: surowe wyniki dostawcy i punkt odniesienia, bez statusów |
| `computed_at` | TIMESTAMP WITH TIME ZONE | NOT NULL |

## api_usage

Dzienny licznik wywołań zewnętrznych API.

| Kolumna | Typ | Uwagi |
|---|---|---|
| `usage_date` | DATE | część PK |
| `provider` | VARCHAR(20) | część PK; `routing` albo `ai` |
| `calls` | INT | NOT NULL |

## trip_log

Zapisany wybór użytkownika. Liczby są migawką z chwili zapisu.

| Kolumna | Typ | Uwagi |
|---|---|---|
| `id` | BIGINT | PK |
| `trip_date` | DATE | NOT NULL |
| `leg_key` | VARCHAR(40) | NOT NULL; bez klucza obcego, historia zostaje po usunięciu punktu |
| `origin_label` | VARCHAR(80) | NOT NULL |
| `destination_label` | VARCHAR(80) | NOT NULL |
| `mode` | VARCHAR(10) | `TRANSIT`, `DRIVE`, `BICYCLE`, `WALK` |
| `summary` | VARCHAR(255) | NOT NULL, opis opcji |
| `distance_m` | INT | NOT NULL |
| `co2_g` | INT | NOT NULL |
| `baseline_co2_g` | INT | NOT NULL |
| `saved_co2_g` | INT | NOT NULL, nigdy poniżej zera |
| `logged_at` | TIMESTAMP WITH TIME ZONE | NOT NULL |

Ograniczenie: UNIQUE (`trip_date`, `leg_key`). Indeks: (`trip_date`).
